# ModbusTool

## 1.简介

基于 Qt4.8 开发的Modbus调试工具，实现快速连接modbus设备进行调试验证。  
功能特性：
- 支持串口和网络(TCP/UDP)通道
- 支持ModbusRTU、ModbusTCP、ModbusASCII协议格式


## 2. 构建环境

- **操作系统**：目标主要针对Windows构建
- **编译器**：MinGW4.8（C++11 / C11）
- **软件框架**： Qt 4.8.7
- **依赖**： 除QT内置模块外不使用任何三方库


## 3. 概要设计

### 3.1 主窗口

主窗口可调整窗口大小，无菜单栏，有状态栏，左侧是连接会话区，右侧是寄存器数据区。  
默认窗口大小为最小尺寸，退出时不需要记住窗口位置和大小。

### 3.2 连接会话区

连接会话区分2个框分别是通道配置和协议配置。

通道配置：
- 通道类型下拉选择串口/TCP/UDP，选则不同通道时下面显示不同的参数输入区；
- 串口号（下拉列表）
- 波特率（下拉编辑框）
- 数据位（下拉列表）
- 停止位（下拉列表）
- 校验位（下拉列表）
- IP地址（编辑框）
- 端口号（编辑框）

协议配置：
- 协议类型:下拉选择ModbusRTU、ModbusTCP、ModbusASCII
- 响应超时时间: 默认1000ms
- 轮寻间隔时间: 默认1000ms
- 单次读取数量: 默认127
- 遥控功能码:05或15
- 遥调功能码:06或16

### 3.3 寄存器数据区

寄存器数据区为表格控件，分为4个TAB页，分别是0区（遥控）、1区（遥信）、3区（遥调）、4区（遥测）；
- 0区（遥控）：对应PLC地址00001-09999，使用01功能码读取，05/15功能码写入
- 1区（遥信）：对应PLC地址10001-19999，使用02功能码读取
- 3区（遥调）：对应PLC地址30001-39999，使用04功能码读取
- 4区（遥测）：对应PLC地址40001-49999，使用03功能码读取，06/16功能码写入

数据区表格包括以下列：
- 序号: 以1开始的行号
- 名称: 用户可编辑的寄存器名字，默认是PLC地址
- 寄存器地址: 0x开头的协议地址
- 数据状态: 成功读取显示有效，否则显示红色的"无效"
- 数据类型: BIT/U16/S16可选
- 原始值:  10进制显示数值
- 设定值: 用户输入的值,仅0区和4区可用
- 写入按钮: 仅0区和4区可用


数据区右键菜单:
- 快速添加：弹出对话框输入起始地址和数量
- 删除点位: 删除选中的行


### 3.4 状态栏

状态栏显示连接状态、通信统计信息；


## 4. 构建与运行
