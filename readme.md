# ModbusTool

## 1. 简介

基于 Qt 开发的 Modbus 调试工具，用于快速连接 Modbus 设备进行调试验证。

功能特性：
- 支持串口和网络（TCP/UDP）通道
- 支持 Modbus-RTU、Modbus-TCP、Modbus-ASCII 协议格式
- 支持多数据类型（BIT/INT16/UINT16/INT32/UINT32/FLOAT32）与字节序选择
- 单点/批量两种读取模式，实时轮询遥测、遥信，支持遥控、遥调写入

## 2. 构建环境

- **操作系统**：Windows
- **编译器**：MinGW 7.3（32 位，C++11 / C11）
- **软件框架**：Qt 5.12.12
- **依赖**：除 Qt 内置模块（core/gui/widgets/network/serialport）外不使用任何第三方库

## 3. 概要设计

### 3.1 主窗口

主窗口无菜单栏、有状态栏；左侧为连接会话区，右侧为寄存器数据区，底部为通信日志区。
最小窗口尺寸与默认启动尺寸均为 960×500。
按 F1 弹出“关于”对话框，显示软件版本号与构建环境。

### 3.2 连接会话区

连接会话区分为通道配置、串口配置、网络配置、协议配置 4 个框，下方留一块可伸缩空白占位区。

通道配置：
- 连接方式下拉选择串口/网络，选择不同方式时显示不同的参数输入区

串口配置（选择串口方式时显示）：
- 串口号（下拉列表）
- 波特率（下拉编辑框）
- 校验位（下拉列表：无/奇校验/偶校验）

网络配置（选择网络方式时显示）：
- 网络协议：下拉选择 TCP/UDP
- IP 地址（编辑框）
- 端口号（编辑框）

协议配置：
- 协议类型：下拉选择 Modbus-RTU、Modbus-TCP、Modbus-ASCII
- 从站地址：默认 1
- 响应超时：默认 1000ms
- 轮询间隔：默认 1000ms
- 读取模式：单点/批量，默认批量
- 遥控命令：05 或 15
- 遥调命令：06 或 16

### 3.3 寄存器数据区

寄存器数据区为表格控件，分为 4 个 TAB 页，依次为 DO/遥控、DI/遥信、AO/遥调、AI/遥测：

| 页 | 区域 | PLC 地址范围 | 读取功能码 | 写入功能码 |
| --- | --- | --- | --- | --- |
| DO/遥控 | 0 | 00001-09999 | 01 | 05/15 |
| DI/遥信 | 1 | 10001-19999 | 02 | 只读 |
| AO/遥调 | 2 | 40001-49999 | 03 | 06/16 |
| AI/遥测 | 3 | 30001-39999 | 04 | 只读 |

数据区表格包括以下列：
- 寄存器名称：用户可编辑的寄存器名字，默认是 PLC 地址
- 寄存器地址：0x 开头的协议地址（可切换 16/10 进制显示）
- 数据类型：遥控/遥信固定为 BIT 不可编辑；遥调/遥测可选 INT16/UINT16/INT32/UINT32/FLOAT32
- 字节序：遥控/遥信为 “-”；16 位可选 AB/BA；32 位可选 ABCD/CDAB/BADC/DCBA
- 原始值：协议数值显示（可切换 16/10 进制显示）
- 设定值：用户输入的值，仅遥控和遥调可用，支持十进制或 0x 开头十六进制
- 操作：写入按钮，仅遥控和遥调可用
- 状态：成功读取显示有效，否则显示红色的失败信息（超时/错误码/无效）

数据区右键菜单：
- 添加点位：弹出对话框输入寄存器地址（支持十进制或 0x 开头十六进制）、数量、数据类型与字节序
- 删除点位：删除选中的行
- 清空列表：删除当前区全部点位（需确认）
- 地址格式：切换寄存器地址列的显示格式（16 进制/10 进制）
- 数值格式：切换原始值列的显示格式（16 进制/10 进制）

表格中寄存器地址、原始值、数据类型、字节序、状态列禁止直接编辑。

### 3.4 状态栏

状态栏显示连接状态、通信统计信息（TX/RX/ERR 报文帧数与错误次数）。

### 3.5 通信日志区

底部通信日志区位于数据区下方，使用纵向分割条与主区分隔，可拖动调整高度。
- 记录收发的完整报文（十六进制）、错误与连接信息，按时间戳、收发方向着色显示
- 支持右键菜单“清空”
- 日志自动裁剪，最多保留最近 2000 行

## 4. 模块结构

| 模块 | 职责 |
| --- | --- |
| `modbuscodec` | 协议编解码（RTU/TCP/ASCII）、CRC/LRC、异常码文本 |
| `modbustransport` / `serialtransport` / `tcptransport` / `udptransport` | `ITransport` 统一接口，I/O 操作一律以 `ErrorCode` 作为返回值 |
| `modbusdevice` | 报文事务收发、线圈/寄存器读写 |
| `modbusworker` | 工作线程，执行轮询与写入请求，持有配置副本 |
| `modbuscontroller` | `IModbusController` 显式接口，UI 直接调用而非信号转发 |
| `commmonitor` | 全局单例，记录收发报文与报文计数器，通过信号通知 UI |
| `errorcodes` | 全局错误码到错误文本的映射 |
| `registertypes` / `registerpoint` | 数据类型与字节序、区域信息与地址格式化 |
| `registerdata` | 数据缓存与变更通知 |
| `connectionpanel` / `registerview` / `commlogview` / `addregisterdialog` / `aboutdialog` | 界面组件 |

线程模型：`ModbusDevice` 与 `ModbusWorker` 运行在独立工作线程。UI 通过 `IModbusController`
接口投递排队调用（配置按值传递），设备与 worker 通过信号槽把结果回传 UI 线程刷新显示。

## 5. 构建与运行

项目提供 `build.bat` 快速编译（内部先 `qmake -r` 再 `mingw32-make all`）；
`run.bat` 可直接运行生成的可执行文件。
