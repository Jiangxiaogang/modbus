# ModbusTool

## 1.简介

基于 Qt4.8 开发的Modbus调试工具，实现快速连接modbus设备进行调试验证。  
功能特性：
- 支持串口和网络(TCP/UDP)通道
- 支持ModbusRTU、ModbusTCP、ModbusASCII协议格式


## 2. 构建环境

- **操作系统**：目标主要针对Windows构建
- **编译器**：MinGW4.8（C++11 / C11）
- **软件框架**： Qt 4.8.7
- **依赖**： 除QT内置模块外不使用任何三方库


## 3. 概要设计

### 3.1 主窗口

主窗口可调整窗口大小，无菜单栏，有状态栏，左侧是连接会话区，右侧是寄存器数据区，底部是通信日志区。  
最小窗口尺寸为 900×500，默认启动尺寸为 900×560，退出时不需要记住窗口位置和大小。  
按 F1 弹出“关于”对话框，显示软件版本号与构建环境。

### 3.2 连接会话区

连接会话区分为通道配置、串口配置、网络配置、协议配置4个框，下方留一块可伸缩空白占位区。

通道配置：
- 连接方式下拉选择串口/网络，选择不同方式时下面显示不同的参数输入区；

串口配置（选择串口方式时显示）：
- 串口号（下拉列表）
- 波特率（下拉编辑框）
- 校验位（下拉列表：无/奇校验/偶校验）

网络配置（选择网络方式时显示）：
- 网络协议:下拉选择TCP/UDP
- IP地址（编辑框）
- 端口号（编辑框）

协议配置：
- 协议类型:下拉选择Modbus-RTU、Modbus-TCP、Modbus-ASCII
- 从站地址: 默认1
- 响应超时: 默认1000ms
- 轮询间隔: 默认1000ms
- 读取模式: 单点/批量，默认批量
- 遥控命令:05或15
- 遥调命令:06或16

### 3.3 寄存器数据区

寄存器数据区为表格控件，分为4个TAB页，分别是0区（遥控）、1区（遥信）、3区（遥测）、4区（遥调）；
- 0区（遥控）：对应PLC地址00001-09999，使用01功能码读取，可选05/15功能码写入
- 1区（遥信）：对应PLC地址10001-19999，使用02功能码读取
- 3区（遥测）：对应PLC地址30001-39999，使用04功能码读取
- 4区（遥调）：对应PLC地址40001-49999，使用03功能码读取，可选06/16功能码写入

数据区表格包括以下列：
- 寄存器名称: 用户可编辑的寄存器名字，默认是PLC地址
- 寄存器地址: 0x开头的协议地址
- 数据类型: 0区/1区固定为BIT不可编辑，3区/4区可选U16/S16
- 原始值:  10进制显示数值
- 设定值: 用户输入的值,仅0区和4区可用
- 写入按钮: 仅0区和4区可用
- 数据状态: 成功读取显示有效，否则显示红色的失败信息(超时/错误码/无效)

数据区右键菜单:
- 快速添加：弹出对话框输入寄存器地址（支持十进制或0x开头十六进制）和寄存器数量
- 删除点位: 删除选中的行
- 清空列表: 删除当前区全部点位(需确认)


### 3.4 状态栏

状态栏显示连接状态、通信统计信息(TX/RX/ERR 报文帧数与错误次数)；

### 3.5 通信日志区

底部通信日志区位于数据区下方，使用纵向分割条与主区分隔，可拖动调整高度。
- 记录收发的完整报文(十六进制)、错误与连接信息，按时间戳、收发方向着色显示；
- 支持右键菜单“清空”；
- 日志自动裁剪，最多保留最近2000行。


## 4. 构建与运行

项目提供build.bat可快速编译
